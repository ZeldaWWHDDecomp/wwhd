# (028F4034) runs real. Not equivalent by design: a frame that starts OUTSIDE [start, end) in NONE/RESET/REVERSE and

# range (init/setFrame), so the domain excludes it. Start 0 (init's value): the HD/GameCube LOOP end wrap sets the
# frame to the remainder itself, not loop + remainder, so with start > 0 it can land below start and the next update's
# start wrap jumps by loop - start; at 30 Hz that happens on the following frame, at N steps inside the same frame.
